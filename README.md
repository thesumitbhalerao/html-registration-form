# 📝 Instagram Registration Form - HTML

This is a beginner-level HTML project created to practice **HTML forms and different input types**.

The project contains an Instagram-style registration form where users can enter their personal information, select options, upload a photo, and submit the form.

## 📌 Project Overview

The registration form includes:

- Full Name
- Username
- Email
- Password
- Confirm Password
- Date of Birth
- Mobile Number
- Profile Photo
- Save & Cancel Button

## 🛠️ HTML Concepts Used

- `<form>` - Creates the form
- `<table>` - Organizes the form fields
- `<tr>` - Creates table rows
- `<td>` - Creates table cells
- `<th>` - Creates table headings
- `<input type="text">` - Text input
- `<input type="email">` - Email input
- `<input type="password">` - Password input
- `<input type="date">` - Date selection
- `<input type="tel">` - Mobile number input
- `<input type="file">` - Photo upload
- `<button>` - Submit & Cancel button
- `required` - Makes fields mandatory
- `colspan` - Merges table columns

## 🎯 Purpose

The purpose of this project is to understand how HTML forms work and how different types of input fields can be organized inside an HTML table.

## 📚 Learning Outcome

Through this project, I learned how to:

- Create an HTML form
- Use different input types
- Create dropdown menus
- Add file upload fields
- Use the `required` attribute
- Organize form fields using a table
- Center the submit button using `colspan`
